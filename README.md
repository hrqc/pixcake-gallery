# 像素蛋糕选片系统 (pixcake-gallery)

直接实时读取像素蛋糕 (PixCake) 的精修照片 (`c_p_f_e`) 和配对原图 (`c_p_f_o`)，
按需生成无水印 JPEG 缓存。**无论有没有导出**，都可在网页里浏览、选片、导出清单。
FXIP 格式已完全逆向破解（见 `fxip/` 与 fxip-format-cracked 记忆）。

## 功能

- 📁 **项目列表**：自动扫描像素蛋糕工作区，每个相册一个选片项目，独立链接
- 🖼️ **实时读取**：打开项目时重新扫描，像素蛋糕里精修完的照片立刻出现（点「刷新」）
- ✅ **选片**：单击选中/取消，双击看大图（键盘 ← → 切换、S 选中、Esc 关闭）
- 📊 **导出 Excel 清单**：全部 / 仅已选，含序号、照片ID、导出文件名、状态、已选时间
- 📦 **下载选中照片**：打包选中照片的完整尺寸 JPG
- 🧹 **自动去水印**：缩略图、灯箱、管理端 ZIP 和客户交付 ZIP 都只使用验证通过的无水印成品
- ⏳ **异步进度**：显示处理/打包进度；任一照片失败会阻止整批 ZIP 并显示照片 ID
- 🚚 **客户交付**：客户只看 375px 无水印预览，摄影师确认订单后才可下载原尺寸 ZIP
- 🔐 **访问令牌**：默认开启，花生壳公网访问时保护隐私
- ✏️ **项目改名**：点击项目名可改显示名（保存在本地数据库）

## 运行

```bash
cd D:\ClaudeGC\pixcake-gallery
python gallery.py [--port 8888] [--ws "工作区根目录"] [--token 令牌] [--no-auth] [--wm-workers 2]
```

- 默认工作区：`D:/xsdg/像素蛋糕/.PixCake-qt_pro Workspace/project`
- 首次运行自动生成访问令牌并保存到 `data/token.txt`
- 启动时会打印各项目的访问链接
- 去水印最多使用 2 个图像线程；成功结果按源文件和算法版本缓存
- 最终编码 JPEG 会再次执行水印残差验证；导出使用独立快照，避免缓存更新影响正在打包的任务

运行依赖：Python 3、OpenCV、NumPy、Pillow、openpyxl；二维码功能另需 segno。

### 花生壳远程访问

1. 花生壳添加映射：内网主机填本机 IP（或 127.0.0.1），内网端口填 `8888`
2. 用花生壳提供的公网地址访问，链接里带上令牌参数 `?t=<令牌>`
3. 浏览器会自动记住令牌（Cookie），之后直接打开即可

## 目录结构

```
pixcake-gallery/
├── gallery.py        # 主服务器 (http.server 标准库)
├── db.py             # SQLite 持久化 (项目/照片/选片状态)
├── scanner.py        # 扫描像素蛋糕工作区 → 发现精修照片
├── watermark.py      # 水印定位、修复和残差验证
├── image_service.py  # FXIP 解码、版本化无水印缓存
├── jobs.py           # 有界异步 ZIP 任务和失败闭锁
├── fxip/             # FXIP 逆向解码模块 (解码 c_p_f_e → JPEG)
├── static/           # 管理端和客户交付端 (单文件, 无框架)
└── data/             # gallery.db, clean-cache/, exports/, token.txt
```

## 数据来源说明

- 每个相册 = 一个选片项目：`<workspace>/<user>/<album>/thumbnail_cache/`
- 精修照片：`<thumb_dir>/c_p_f_e/<ID>_3000`（FXIP 加密预览，解码为 JPEG）
- 配对原图：`<thumb_dir>/c_p_f_o/<ID>_3000`
- 只有**精修过**的照片才会出现在 c_p_f_e，因此天然过滤「只显示精修」

## 已知限制

- 照片名是像素蛋糕内部 ID（如 `1A0A3296`），非原始文件名（原始文件名未保存在缓存中）
- 单个源文件损坏或 E/O 配对异常时会失败关闭，不会回退输出带水印照片；重新精修该照片后可自动重试
