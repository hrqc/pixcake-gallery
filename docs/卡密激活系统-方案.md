# 卡密激活系统 方案 (v1, 待审核)

> 目标：选片系统产品化，卖给其他摄影师。摄影师购买卡密激活后才能使用系统；
> 未激活/过期/超额 → 完全锁死（登录即拦截）。客户选片页不受影响。

## 1. 架构

```
摄影师电脑(客户端软件)                授权服务器 (43.129.180.22)
┌──────────────────────────┐        ┌──────────────────────────────┐
│ gallery 选片系统          │        │ gallery + 授权模块(license)   │
│  + 激活模块               │ ─激活─▶ │ /api/license/activate        │
│  卡密输入 → 提交机器码     │ 卡密    │ 卡密库 license_keys(SQLite)  │
│  本地授权文件 license.json│ +机器码  │ 管理端: 生成/禁用/统计/导出   │
│  每天在线续期校验一次      │ ◀─返回─ │                             │
└──────────────────────────┘  授权结果 └──────────────────────────────┘
```

- **授权服务器 = 你的 43.129.180.22**（已有公网 + Caddy，域名过审后走 HTTPS）
- **客户端软件 = 你现在这套系统**（别人部署后先激活才能进管理端）
- 激活成功后本地存 `data/license.json`，软件启动时读它判断能否用

## 2. 卡密类型（一张表统一支持）

| 类型 | 参数 | 行为 |
|---|---|---|
| 时间卡 | 月/季/年卡，`duration_days` | 到 `expires_at` 锁定 |
| 永久卡 | `duration_days=0` | 永不过期 |
| 张数卡 | `quota>0` | 按精修交付张数扣额度，扣完锁定 |
| 绑定设备 | `bind_device=1` | 激活时锁定机器码，防一个卡多人用 |

任意组合：时间+绑设备、张数+绑设备等。

## 3. 数据表 `license_keys`

```sql
key           TEXT PRIMARY KEY   -- 卡密 XXXX-XXXX-XXXX-XXXX
plan_name     TEXT               -- 套餐名(月卡/季卡/年卡/永久/张数卡)
duration_days INTEGER DEFAULT 0  -- 0=永久
quota         INTEGER DEFAULT 0  -- 0=不限; >0=张数额度
bind_device   INTEGER DEFAULT 0  -- 1=绑机器
status        TEXT               -- unused/active/disabled/expired
bound_fp      TEXT               -- 绑定的机器码 hash
activated_at  INTEGER
expires_at    INTEGER
quota_used    INTEGER DEFAULT 0
created_at    INTEGER
remark        TEXT               -- 备注(客户名/订单号)
```

## 4. 接口

| 接口 | 说明 |
|---|---|
| `POST /api/license/activate` | 客户端激活：提交 卡密+机器码 → 校验/绑设备 → 返回授权信息 |
| `POST /api/license/verify` | 客户端每天在线续期校验：返回 有效/过期/已禁用 |
| `GET/POST /api/license/admin/*` | 管理端（带你的管理 token）：生成/列表/禁用/延期/统计/导出 |

## 5. 客户端改造（摄影师的软件）

1. 启动/进管理端前检查：`license.json` 存在且未过期/未超额 → 正常用
2. 否则跳**激活页**：输入卡密 → 提交机器码 → 在线激活 → 存授权文件
3. 每天一次调 `verify` 续期校验（防改本地时间 / 篡改授权文件）
4. **客户选片页 `/d/<code>` 不走卡密**（客户无需激活）

机器码 = MAC地址 + 主机名 的 sha256 前 24 位（简单可靠，够用）

## 6. 管理端（你在授权服务器上操作）

- 批量生成卡密：选套餐类型 + 数量 + 备注 → 一次生成 N 张
- 卡密列表：卡密 / 套餐 / 状态 / 绑定设备 / 激活时间 / 到期 / 用量
- 操作：禁用 / 启用 / 延期 / 作废（客户退款场景）
- 导出：全部或未激活的卡密导出为 Excel / 文本（方便卖卡发码）
- 统计：各套餐 生成数 / 已激活 / 到期 / 绑定设备数

## 7. 安全

- 卡密格式 `XXXX-XXXX-XXXX-XXXX`，去 0/O/1/I 易混字符，含校验位防乱输
- 激活接口限流（同 IP 防刷）
- 机器码只存 hash，不存原值
- 在线验证 + 到期锁死；本地授权文件加密签名（防手改）
- 完全防破解需客户端加壳混淆，属"做软件"阶段的加固，本期先不追求
